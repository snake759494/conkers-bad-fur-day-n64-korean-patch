# 기술 문서

## 자산 구조
- ROM 0xAB1950 에 세그먼트 29개의 (오프셋, 크기) 표. 세그먼트 → 컨테이너 → 파일의 3단 테이블.
- 압축은 RareZip: 압축 해제 길이 4바이트(빅 엔디언) + raw deflate.
- 레벨 파일 안의 섹션 표 (오프셋, 플래그|크기), 대사 섹션은 NUL 종료 문자열.
- 대사는 세그먼트 6(게임 본편)·26(튜토리얼 등), 메뉴·챕터 이름·스태프롤은 세그먼트 28.

## 텍스트 제어 바이트
| 값 | 의미 |
| --- | --- |
| `0x0A` | 줄바꿈 |
| `0xBD` | 말풍선 페이지 넘김 |
| `0xBC` | 2바이트 확장 |
| `0xA1`~`0xA7` | 글자 색 |
| `0xA8`~`0xBA` | 버튼 아이콘·삐 처리 기호 |

## 한글 부호
글자 번호 k(0~2047)를 `0x80+(k>>6)`, `0xC0+(k&63)` 두 바이트로 씁니다. 원래 0x80~0x9F 는 쓰지 않는 값이라 선행 바이트로 구분됩니다.

## 게임 코드
- 0x15000000 대역(TLB 매핑)의 게임 코드는 4KB 단위 RareZip 청크. 오프셋 표(ROM 0x42450)는 0x8039CCCA 로 XOR, 데이터는 +0x145ED8 부터.
- 원래 글꼴: I8, 글리프당 0xE0 바이트(0x800C68B0), 크기 표(w,h,xoff,yoff) 0x800CBBD0. 홀수 행은 4바이트 워드가 스왑된 형식.

## 후크
| 위치 | 내용 |
| --- | --- |
| 0x15041BD8 (그리기 함수의 jal) | `KMAP_D`: 2바이트 한글이면 글자 번호 계산 |
| 0x15042968 (폭 계산 함수의 jal) | `KMAP_M`: 한글은 고정 폭, 포인터 1바이트 추가 전진 |
| 0x15042458 → 0x15042460 | `KTEX`: 텍스처 포인터를 한글 글리프로 교체 (`$ra` 가 살아 있어 `jal` 대신 `j`) |
| 후크 코드 | 0x151FA140 (코드 마지막 페이지) |

한글 글리프는 쓰이지 않는 슬롯 0x5D(Ù)를 빌려 그리기 직전에 텍스처 주소만 바꿉니다. 슬롯의 크기 값은 (w=13, h=13, 0, 0)으로 쓰고, 글리프는 14행 텍스처의 1행부터 그려 맨 윗줄이 잘리지 않게 합니다(v1.0.1).

## 글꼴 적재
게임은 4MB만 쓰므로 한글 글꼴 블롭(838자, 약 0x2DD40 바이트)을 확장팩 영역 0x80401000 에 올립니다. 부트 초기화 코드 0x100044EC 에서 여백 0x100226A0 의 로더를 호출해 `osPiRawStartDma`(0x10023850)로 ROM 빈 공간(0x3F8B800 이후)에서 복사하고 `osPiGetStatus` 로 완료를 기다립니다.

## 체크섬
부트 영역을 고쳤으므로 CIC-6105 체크섬을 다시 계산해 헤더에 씁니다.
